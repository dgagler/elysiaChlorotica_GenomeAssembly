# Genome assembly of Elysia chlorotica
Pipeline for the genome assembly of the sacoglossan sea slug *Elysia chlorotica*. Currently, this repo is strictly for the assembly of PacBio HiFi data, but this project is aimed as generating a chromosome-level reference assembly. Iso-Seq data already exists, although its quality is yet to be determined. Hi-C data is anticipated for scaffolding.
